## Non-negotiable limitation on the phrase “full original value”

A source-faithful synthesis can preserve major reusable **techniques**, examples, decision boundaries and references; it cannot truthfully claim equivalence to every specialized branch in hundreds of upstream documents without running additional source-to-output semantic comparisons and live model evaluations. This release improves substantially on v0.2 but **does not claim exhaustive semantic preservation or guaranteed user growth**. The 103 upstream URLs and source cache verifier support further audits without bundling other authors' text.

## Re-audit trigger

Repeat the source comparison when a pinned upstream version changes, the system expands to a new social platform, the user's account/target audience evolves, current platform rules change, or a real-agent test finds an important missing technique. Require documented correction and regression test before promoting a new version.
