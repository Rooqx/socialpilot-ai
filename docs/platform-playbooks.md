# Platform-native authoring guides (not live platform specs)

## X
Single post = one strong observation, practical tip, source-grounded claim, or question. A thread is justified when sequencing adds value. Use one substantive point per item and natural transitions. Validate current post character limits and account eligibility before handoff; Unicode, links and other media may have platform-specific counting rules. Do not promise algorithm benefits or penalize links based on unsourced multipliers.

## LinkedIn
Feed posts prioritize credible professional experience, actual technical details and natural paragraph pacing. Avoid fake career achievements and excessive line breaks. Document posts are a **different artifact** from plain text feeds; plan a slide deck, export, and visual QA. Check current post/document length and format specs with primary LinkedIn documentation before export. Conclude with real lessons rather than compulsory comments bait.

## Instagram
Visual drives the post: first decide photograph, carousel, Reel or Story, then write copy that actually matches the media. Carousels need a coherent mobile-readable slide hierarchy and accurate alt text. Reels need a timed voiceover, scene list and visible captions. When images/video are missing, return `brief_only` and draft caption, not `rendered_verified`. Check current image sizes, limits and accessibility/metadata controls before posting. Hashtags should be relevant, not stuffed for imaginary reach.

## Cross-platform
Repurpose claims, not copy-and-paste whole captions. Respect copyright and privacy. Measure each format on its own platform and time window; never compare incomparable view/reach counters as direct equivalents.
