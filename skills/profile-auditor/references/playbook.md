# Profile clarity and evidence audit

## Separate identity from platform mechanics

Use only actual publicly viewable or user-provided profile sections. Never infer account ownership from a similar handle. Profile improvements must be grounded in confirmed background, offerings and platform goals—not invented job titles, awards or conversion statistics.

## Platform-specific checklists

**X:** Display-name clarity, who the account helps, topical signal, appropriate link, pinned-post relevance, header readability and a concise bio.

**LinkedIn:** Accurate headline, About opening, verified work history, concrete featured evidence, audience path to contact, banner contrast and accessible content. Suggest edits without fabricating employment or certifications.

**Instagram:** Searchable name, audience promise, category, link destination, pinned content, highlight organization, profile image readability and coherent but flexible visual presentation.

## Deliverable

1. Audit existing fields with evidence links or clear "not accessible" notes.
2. Score *clarity and factual integrity* qualitatively—not predicted algorithm growth.
3. Provide an annotated before/after recommendation for each important field with explicit factual dependencies.
4. Prioritize changes by expected reader understanding and effort. A clear value proposition usually outranks decorative tweaks.
5. Distinguish proposed copy and approved copy. No account changes without current, specific user authorization.

## Example

Weak headline: "Passionate developer seeking to revolutionize the world." Better *if true*: "Full-stack developer building React and Node.js applications | Portfolio and project walkthroughs." Confirm the technology stack and actual role before using the suggestion as personal fact.

## Failure cases

The user submits another person's profile for reference; a private section cannot be seen; the website link redirects incorrectly; a claimed credential is not supported; the assistant treats its suggested bio as already live. Flag each explicitly.
