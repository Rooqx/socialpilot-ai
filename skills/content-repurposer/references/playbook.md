# Derivative content with factual lineage

## Reuse the idea, not the surface copy

A repurposed family shares a factual thesis and source provenance but adapts delivery to each destination. Mark `family_key` on every derivative and link each new assertion to its source. A new example introduced during adaptation must be verified separately.

## Repurposing matrix

| Source | X | LinkedIn | Instagram |
|---|---|---|---|
| Technical article | One sharp consequence or tutorial thread | Implementation tradeoff with context | Diagram carousel explaining the flow |
| Verified project walkthrough | One reusable lesson | Evidence-based project narrative | Actual screenshot sequence with caption |
| Interview/transcript | Short attributed takeaway | Nuanced synthesis and context | Quote card only with permission and accurate attribution |
| Data report | Source-linked observation | Method + key finding + caveat | Clearly labeled chart with correct denominator |

## Workflow

1. Verify ownership/permissions for source and supporting media. Identify what can be paraphrased and what requires attribution.
2. Extract 3–5 genuinely independent insights: claim, reader benefit, supporting evidence, missing context and media needs.
3. Choose the best destination form per idea, not automatically one output for every platform.
4. Write each variant with native structure and a *different useful entry point*. Preserve facts and uncertainty exactly.
5. Check semantic overlap with previously posted material, and attach family links for measurement.
6. Run claim verification and asset checks on each derivative, not just the source document. Record publication authorization separately for each account.

## Example

Source: a user-written postmortem about a background job retry. X: why timeouts make idempotency necessary. LinkedIn: context/options/tradeoff from the verified incident. Instagram: storyboard explaining the request timeline. The Instagram package is not complete without rendered slide assets and checked caption correspondence.

## Failure criterion

Five crops of the same sentence are not five independent posts. Attribution omitted, context changed, anonymous quotes treated as consented testimonials, media unavailable, or an inferred result promoted to verified fact all require revision.
