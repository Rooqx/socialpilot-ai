# Platform adaptation decision table

| Choice | X | LinkedIn | Instagram |
|---|---|---|---|
| Native strength | Concise conversation and ordered threads | Professional evidence and useful explanations | Strong visual narrative, video and contextual caption |
| First screen | Clear claim or observation | Specific professional stakes and example | Legible cover or opening visual matching the promise |
| Depth | Single point; thread only when necessary | A worked experience, reasoning or framework | Slide-by-slide or shot-by-shot with supporting caption |
| Common failure | Cramming a tutorial into one post | Generic motivation with fabricated credentials | Caption about a visual that does not exist |
| Best evidence | Short linked source or reproducible example | Actual project steps and limits | Visible proof, accurately captioned and attributed |

## Verification boundary

Platform character limits, media dimensions, API eligibility and moderation rules change. Static templates are **starting points**, not evidence of current compliance. For any genuine publishing handoff, verify the relevant constraints from platform documentation, note the date, and adapt to the specific connected account where that changes available features.

## Method

1. Identify goal, audience, topic and whether the request is primarily text, document, image or short-form video.
2. Build a common factual brief first; preserve facts through all adaptations.
3. Choose native treatment independently per platform instead of mechanically abbreviating or elongating identical copy.
4. Verify claims and asset availability. If an Instagram visual is only a brief, mark the deliverable as `brief_only` rather than finished post.
5. Report which hard platform constraints were checked, which remain unknown and what account-specific limits still need validation.

## Scenario

A developer teaches how retry storms happen. X receives one counterintuitive takeaway with a concrete example. LinkedIn receives a grounded incident analysis with tradeoffs and qualifications. Instagram receives a concise "why retries multiply work" sequence and a caption that references the **actual** graphics. None may claim real personal experience unless provided by the creator.
