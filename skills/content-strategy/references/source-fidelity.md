# Technique-by-technique source fidelity — content-strategy

This ledger maps **re-authored editorial/operational techniques** to their upstream intellectual sources. It is not a claim of verbatim import or exhaustive preservation of every upstream sentence. Each method is reviewed for portability, current platform evidence, and risks.

| Method | Specialist implementation | Origin / rationale |
|---|---|---|
| M01 Goal-to-behavior map | Specify audience outcome, business or creator goal, available effort and observable platform-native indicators | BlackTwist content-strategy discovery |
| M02 Pillars and clusters | Derive a small set of pillars from credible expertise and audience problems; split each into topic clusters and specific proof-backed questions | BlackTwist content-strategy pillar and topic cluster |
| M03 Searchable/shareable distinction | Separate evergreen, query-led knowledge from timely stories and discussion ideas | Corey content-strategy searchable versus shareable |
| M04 Differentiation test | For each pillar identify what the creator can demonstrate from direct experience, how that view differs from generic competitor content, and which claims must be proven | Kostja branding and BlackTwist differentiation |
| M05 Production system | Map the content idea through research, draft, art needs, review, platform, cadence and capacity | Corey distribution and BlackTwist capacity planning |
| M06 Learning cadence | Reassess pillar fit from real saves, replies, qualified visitors and user feedback, not one viral outlier | Corey loops and BlackTwist performance analysis |
