# Technique-by-technique source fidelity — hook-optimizer

This ledger maps **re-authored editorial/operational techniques** to their upstream intellectual sources. It is not a claim of verbatim import or exhaustive preservation of every upstream sentence. Each method is reviewed for portability, current platform evidence, and risks.

| Method | Specialist implementation | Origin / rationale |
|---|---|---|
| M01 True central promise | Write the useful insight in a sentence before generating openings | BlackTwist hook-writer promise alignment |
| M02 Pattern diversity | Try direct finding, story tension, problem recognition, careful contrarian, specific how-to, question, and data-supported claim; use evidence only when supplied | BlackTwist nine hook families |
| M03 Six-variety test | Produce meaningful variants representing different reader motivations, not six thesaurus rewrites | Charlie hook-generator variations |
| M04 Platform adaption | For X, frontload the complete thought; for LinkedIn, make the opening stand alone without formulaic broetry; for Instagram, align on-image cover and caption | Kostja and BlackTwist platform hook approaches |
| M05 Integrity sweep | Reject manufactured surprise, unsupported achievements, false scarcity or engagement bait | Corey social no-AI-tells and copywriting |
