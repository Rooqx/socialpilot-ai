# Technique-by-technique source fidelity — idea-pipeline

This ledger maps **re-authored editorial/operational techniques** to their upstream intellectual sources. It is not a claim of verbatim import or exhaustive preservation of every upstream sentence. Each method is reviewed for portability, current platform evidence, and risks.

| Method | Specialist implementation | Origin / rationale |
|---|---|---|
| M01 Eight-way angle expansion | Cross a small set of verified subject insights with formats such as tutorial, mistake, comparison, opinion, breakdown, mini-story, checklist and Q&A; discard angles that require fabricated details | Charlie content-matrix |
| M02 Idea record | Store premise, target reader, content pillar, proof asset, freshness, proposed native formats, last-use date and confidence | Corey marketing-ideas classification |
| M03 Priority score | Rank by usefulness, evidence readiness, novelty, strategic fit and expected effort; label scoring as editorial estimation until performance data exists | BlackTwist content-pattern-analyzer and strategy |
| M04 Audience-language sourcing | Capture a real question or friction point rather than using an invented controversy | Corey customer-research |
| M05 Idea lifecycle | Move from discovered → briefed → drafted → published/reported → evaluated; do not erase failed ideas because their negative evidence is useful | Corey marketing-loops state discipline |
