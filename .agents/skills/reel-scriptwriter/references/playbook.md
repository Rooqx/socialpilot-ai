# Short-form script-to-production playbook

## A Reel is a timed audiovisual deliverable

A script is not footage. Before promising output, list which elements exist: recorded voiceover, screen recordings, demonstration, photographs, generated art, music license, captions and editing tool. If a component does not exist, mark it as a production dependency.

## Story and shot design

1. Write one takeaway that can be shown or said within the requested duration. Divide it into a credible opening, body and payoff.
2. Storyboard each segment as `start/end`, `visual or screen action`, `voiceover`, `on-screen text`, `asset source`, and `editor note`.
3. Estimate spoken duration from actual word count and natural narration pace, but treat it as an estimate until tested with audio.
4. Make the opening useful immediately—actual UI behavior or a specific problem, not exaggerated claims about outcomes.
5. Design caption readability with no essential information conveyed *only* through sound or color.
6. Request missing screen recordings when the story depends on a feature that has not been captured. Don't replace real product behavior with a fabricated mockup presented as proof.
7. If rendering is requested and a tool is available, inspect the output for clipping, spelling, transitions and audio clarity. Otherwise hand back a production-ready script and asset checklist.

## Example timing plan (illustrative only)

0–3s: show a failing API response; voiceover introduces the debug question. 3–12s: point to a missing runtime setting. 12–25s: demonstrate the corrected setup with an *actual* recording. 25–30s: one preventive check. Shorten material if spoken words exceed comfortable timing rather than falsely claiming a 30-second video exists.

## Adversarial QA

Third-party clip rights unknown; user requests competitor Reel download with no permission; AI-created UI shown as actual product; caption not matching narration; an important code line too small to read; unlicensed sound; script says "as you can see" for absent footage. Any of these blocks finished-video status.
